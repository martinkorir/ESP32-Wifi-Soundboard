# ESP32-Wifi-Soundboard
A wireless sound triggering system built around an ESP32 microcontroller, a DY-SV5W voice playback module, and 8 Ohm speaker. 
It can play 5 pre-loaded sounds remotely. Good for hidden speaker pranks! Also learned how to solder on this project for the audio module

## Pin configuration
ESP32 GPIO Pins → DY-SV5W Module
- GPIO 25 → Sound 1 trigger
- GPIO 26 → Sound 2 trigger
- GPIO 27 → Sound 3 trigger
- GPIO 14 → Sound 4 trigger
- GPIO 12 → Sound 5 trigger
I2C Display:
- SDA → GPIO 21
- SCL → GPIO 22
